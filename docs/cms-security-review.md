## Attack-surface map

- **publicPages:** Legacy public site plus typed CMS EN/FR/ES page/product/editorial routes and public sitemap/robots; new Worker publishes projected visible content into escaped HTML/JSON.
- **dynamicRoutes:** GET /api/cms, /api/cms/document; authenticated GET /api/admin/content, /content/revisions, /content/revisions/N; PUT /content/draft; POST /content/validate, /content/publish, /content/rollback; POST /api/admin/media; GET/HEAD /api/admin/media/<key>; GET /api/admin/recovery/backup, /recovery/orphans; POST /recovery/restore; public GET/HEAD /media/upload-<uuid>.<jpg|png|webp>.
- **authSession:** Cloudflare Access RS256 assertions, issuer/audience and subject/email allowlist; no local passwords, sessions or frontend auth authority. Synthetic local signer/JWKS are scratch-only harness, production entry unchanged.
- **databaseStorage:** Singleton site in D1; append-only revisions with version-CAS transactional pointers; R2 uploads private by application design; durable D1 upload reservations. Legacy production KV fixed read-only key.
- **uploads:** Raw JPEG/PNG/WebP only, 8 MiB streamed cap, 8192 dimension and 12M pixel max, strict containers + Images decode/re-encode, UUID object names, protected previews/current publication-gated public reads.
- **outboundFetch:** Restricted configured Access cert endpoint only; fixed ASSETS service binding requests. Browser external HTTPS links/images are not server URL imports.
- **adminPrivate:** /admin[/...] and every /api/admin path gated before fallback; same shared permission for every allowlisted editor, including backup and publication. No tenant/customer accounts.
- **paymentsWebhooks:** None. Product prices are editorial display; booking prepares WhatsApp inquiry without server submission/payment or stored customer bookings.
- **aiSpend:** No AI endpoint; D1/R2/Images and revision/backup CPU/storage are spend-sensitive. Upload budgets are durable, other CMS read/write rates and revision growth are not bounded.
- **logging:** Worker no console logging; generic errors; private actor subjects in immutable revision/accounting records. Provider/Access/CI log access/retention unknown.
- **recovery:** Authenticated export contains documents + media hash manifest, NOT object bytes; restore validates manifests/objects then adds draft only; orphan route dry-run only; local stopped-state snapshot includes D1/R2 bytes with symlink/overlap/integrity checks. No remote offsite backup/restore operations proven.
- **ciArtifacts:** No tracked CI workflow. Vite build + Worker dist assets; ignore dist/.wrangler/logs/.cms-backups; .dev.vars* not ignored. Fresh isolated parent build succeeded but final release output manifest scan remains open.
